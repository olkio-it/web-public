# olkio-it/web-public

Veřejná publikace webu **OLKIO.IT** (olkioit.cz) na GitHub Pages.

- `site/` – hotový web. **Needitujte ručně**: obsah sem automaticky zapisuje workflow
  „Publikace webu“ z (privátního) repozitáře `olkio-it/web` při každé změně ve složce `src/`.
- `.github/workflows/pages.yml` – nasazení `site/` na GitHub Pages.

Změny webu dělejte v repozitáři `olkio-it/web`, viz `docs/infrastruktura.md`.
